# Week 11: CRS Checks and Spatial Operations

## What this folder contains
- area_wrong_and_right.py: shows the need to reproject CRS for measurement
- set_vs_to.py: showing the difference berween assigning a CRS and reprojecting
- one_point.py: converts one coordinate point to a different CRS
- spatial_ops.py: performs spatial operations like join
- coverage_gap.py: performs buffer and dissolv operations
- nearest.py: performs spatial operation with centroid, nearest join
- clip_dissolve.py: performs spatial operation like clip, buffer
- fix_geometry.py: fixes geometry of a polygon
- Project scripts: All py files written with my project as a case study

## How to run it
From the repository root:
uv run month-03/week-11/

I realized a lot of spatial operations that are done on QGIS can aslo be implemented using Geopandas in python
